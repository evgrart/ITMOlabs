# Лабораторная работа 1  
Ввод и вывод: из файла input.txt, input.json, input.csv  
Вывод: в файл output.txt, output.json, output.csv

## Задание 1  
Написать скалярное умножение векторов, вектора задаются последовательностью чисел в input.txt, вывести 1 число

**Пример input.txt**
```
1.5 2 -3 4.2
0.5 -1 2 -0.5
```

**Пример output.txt**
```
-3.3
```

## Задание 2  
Написать сложение векторов-матриц-тензоров, в первой строке задается размер Матрицы `n_0 n_1 ... n_m`, $0<m<100, \Pi n_i <= 2^16 $
Затем две матрицы построчно (или вложенный массив в json), между числами пробел

**Пример input.txt**
```
3 3
1 2 3
4 5 6
7 8 9
0 1 1
2 0 3
4 1 -2
```

**Пример output.txt**
```
1 3 4
6 5 9
11 9 7
```

## Задание 3  
Написать умножение матриц,  
В первой строке задается размер n, m, $n*m<=2^16$
Далее вводятся две матрицы $n \times m$ и $m \times k$

**Пример input.txt**
```
2 3

1 0 2
3 1 4

3 2
5 6
7 8
```

**Пример output.txt**
```
2 2
23 8
62 26
```
