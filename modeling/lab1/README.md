# Моделирование — лабораторная работа 1

Вариант 11. Статистический анализ результатов измерений.

- `report_variant11.pdf` — готовый отчёт;
- `analyze.py` — расчёт характеристик, генерация выборки, построение графиков;
- `model.py` — статистические формулы и гиперэкспоненциальный генератор;
- `!_УИР1_Варианты_с.xlsx` — исходные данные: лист `1-50`, диапазон `L2:L301`;
- `requirements.txt` — зависимости программы;
- `results/` — результаты расчётов, таблицы Excel и CSV, графики PDF.

## Запуск

Использован Python 3.14. Из каталога `modeling/lab1`:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe analyze.py
```

Программа создаёт результаты в `results/`. Начальное значение генератора
по умолчанию — `11`, как в отчёте. Новая реализация с отдельным каталогом результатов:

```powershell
.\.venv\Scripts\python.exe analyze.py --seed 12 --output demo_results
```

## Результаты

`results_variant11.xlsx` содержит исходные и сгенерированные значения,
числовые характеристики, доверительные интервалы и автокорреляции.
`results.json` сохраняет результаты без округления. CSV-файлы содержат
те же данные в открытом табличном формате.

Обработаны первые 10, 20, 50, 100, 200 и 300 наблюдений.
Дисперсия в таблицах исправленная, с делителем `n-1`.
Доверительные полуинтервалы рассчитаны по коэффициентам из теории:
1,643; 1,960; 2,576. Параметры модели H₂ согласуют два эмпирических
начальных момента. Качество аппроксимации и её ограничения описаны в отчёте.
