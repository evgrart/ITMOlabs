# Лабораторная №2 — Warhammer 40K

Теория, примеры запросов и ответы на вопросы для защиты: [theory.md](theory.md).

В `main.pl` объединены парсер, диалог, рекомендации, объяснения и демонстрационные сценарии. База знаний подключается из `../lab1/knowledge_base.pl` — папки lab1 и lab2 должны оставаться рядом.

## Запуск

Нужен только SWI-Prolog:

```powershell
cd D:\ITMO\ITMOlabs\systems-of-artificial-intelligence\lab2
swipl -q -s main.pl
```

Если команда swipl не найдена:

```powershell
& "$env:LOCALAPPDATA\Programs\SWI-Prolog\bin\swipl.exe" -q -s main.pl
```

## Ввод

Первый ответ — строка фиксированного вида:

```text
Сторона: Хаос; роль: псайкер
```

Затем программа спрашивает:

1. Минимальный учебный рейтинг 0..10. Enter означает 0.
2. Нужного союзника. Enter означает отсутствие ограничения.

В примере введи `8` и нажми Enter на вопросе союзника: результатом будет Ариман.

Стороны: Империум, Хаос, ксеносы, любая. Несколько сторон разделяются запятой.

Роли: псайкер, военачальник, не псайкер, псайкер и военачальник, псайкер или военачальник, любая.

Имена союзников можно вводить по-русски или атомами из lab1: `ahriman`, `abaddon` и т. д. Команды `выход`, `exit`, `quit` отменяют подбор. Ошибочный ввод вызывает повтор текущего вопроса.

## Демонстрация

```powershell
swipl -q -s main.pl -- --demo
```

| Предпочтения | Рейтинг | Союзник | Результат |
| --- | --- | --- | --- |
| Хаос; псайкер | 8 | Нет | Ариман |
| Ксеносы; не псайкер | 8 | Нет | Имотех |
| Империум; любая роль | 0 | Нет | Жиллиман, Мефистон |
| Хаос; военачальник | 8 | Ариман | Абаддон |
| Хаос, ксеносы; не псайкер | 9 | Нет | Абаддон |
| Империум; псайкер | 8 | Нет | Совпадений нет: рейтинг Мефистона — 7 |

Показ сформированного запроса во время обычного диалога:

```powershell
swipl -q -s main.pl -- --show-query
```

Программа разбирает строку, уточняет ограничения, строит Prolog-терм и выполняет его по базе lab1. Дубликаты удаляются; персонажи сортируются по убыванию рейтинга и затем по имени. Каждый результат сопровождается объяснением. Если точных совпадений нет, показываются причины отказа без автоматического ослабления условий.

Рейтинг угрозы и союзничество — учебные допущения первой лабораторной, а не официальные параметры Warhammer 40K.
